    Time complexity

    How each operation scales as the list grows. The active operation is highlighted.

    OperationTimeWhy
    get(i)O(1)Jumps straight to the slot by index.
    set(i, e)O(1)Overwrites one slot by index.
    append(e)O(1)*Amortized. A rare resize copies all n elements.
    add(i, e)O(n)Shifts up to n elements right to open a slot.
    remove(i)O(n)Shifts up to n elements left to close the gap.
    size()O(1)Reads the stored size field.
    getCapacity()O(1)Reads the backing array's length.
    Big-O shows how the work grows with the list size n, ignoring constants.
    *amortized: usually O(1), but a rare resize copies all n elements.
